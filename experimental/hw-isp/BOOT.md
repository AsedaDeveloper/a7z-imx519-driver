# Surviving a reboot (checklist B3)

After a reboot the camera is there and `/dev/video9` is already serving. Nothing has to be run by hand.

## The trap this fixes
`/boot/extlinux/extlinux.conf` is generated by `u-boot-update`, which runs from package hooks. The camera's device-tree overlay was being applied only by a
hand-added `l0cam` entry, and the overlay file was named `cubie-a7z-imx519-j5-isp.dtbo.trial`. `u-boot-update` globs `*.dtbo`, so the `.trial` suffix excluded
it from every generated entry, and each regeneration reset `default` to `l0` — which carries no overlay. The symptom is total: `sunxi-vin-media: probe ... failed`,
no `/dev/video0` at all.

**It bit twice in one day.** Once after a reboot, and again right after the apt installs for B19 regenerated the file.

The fix is to let the supported mechanism do it: a copy of the overlay named plain `.dtbo`, so `u-boot-update` puts it on every entry it writes.

```sh
sudo cp /boot/dtbo/cubie-a7z-imx519-j5-isp.dtbo.trial /boot/dtbo/cubie-a7z-imx519-j5-isp.dtbo
sudo u-boot-update
```
The default entry then carries `fdtoverlays /boot/dtbo/cubie-a7z-imx519-j5-isp.dtbo`, and regeneration keeps it.

## The service
`tools/a7z-camera.service` loads v4l2loopback and runs `tools/a7zstream.sh` in `A7Z_NODE=/dev/video9` mode under systemd, with `Restart=always` on top of the
supervisor's own exit-code handling (3 = encoder wedged, reload `sunxi_ve`; 4 = capture stalled). Module options also live in `/etc/modprobe.d/v4l2loopback.conf`.

```sh
sudo install -m755 tools/a7zstream.sh /usr/local/bin/
sudo install -m644 tools/a7z-camera.service /etc/systemd/system/
sudo systemctl enable --now a7z-camera
```
To stop the camera claiming the ISP at boot: `sudo systemctl disable --now a7z-camera`.

## Verified
Two reboots. After the second, with nothing typed:

```
systemctl is-active a7z-camera   -> active
/dev/video9                       -> present
cv2.VideoCapture(9)               -> 15/15 frames, (1080, 1920, 3)
HEALTH                            -> 30.0 fps, 0 drops
```
